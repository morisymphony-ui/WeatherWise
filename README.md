# 🌦️ WeatherWise

سامانه ی هوشمند گزارش آب وهوا — سریع، چندزبانه، امن، و با جلوه های بصری ای که واقعاً با زمان روز و وضعیت هوا هماهنگ می شن.

---

## ✨ ویژگی ها

### 🌍 داده ی آب وهوا
- دریافت آب وهوای لحظه ای، پیش بینی **امروز/فردا** (ساعت به ساعت) و پیش بینی **هفتگی** (7 روزه)
- سه منبع داده به صورت زنجیره ی fallback خودکار: **WeatherAPI** (اصلی) ← **Open-Meteo** ← **OpenWeatherMap**، تا قطعی یک سرویس باعث از کار افتادن کل سایت نشه
- برای هر روز توی پیش بینی هفتگی، وضعیت **روز و شب به صورت کاملاً جداگانه** محاسبه می شه (نه یک مقدار تکراری برای هر دو)

### 🗺️ جست وجوی هوشمند شهر
- جست و جو و پیشنهاد زنده (autocomplete) حین تایپ
- پشتیبانی از جست وجوی شهرهای ایرانی و خارجی **به فارسی**، با یک زنجیره ی چندلایه برای ترجمه/تطبیق اسم شهر:
  1. دیکشنری مطمئن شهرهای معروف ایران
  2. دیکشنری شهرهای معروف خارجی نویسه گردانی شده (نیویورک، برلین، مسکو، ...)
  3. کتابخانه ی Geographer
  4. سرویس ترجمه ی رایگان MyMemory (بدون نیاز به کلید API)
  5. حرف نویسی خودکار فارسی به لاتین، به عنوان آخرین راه حل
- نرمال سازی حروف عربی/فارسیِ هم شکل (مثل ي/ی و ك/ک) تا تفاوت های نامرئی یونیکد باعث شکست جست وجو نشن
- نمایش اسم ترجمه شده ی شهر در کنار اسم اصلی (در صورت متفاوت بودن)
- جست وجو کاملاً مستقل از زبان نمایشه — تغییر زبان رابط کاربری هیچ وقت نتیجه ی جست وجو رو عوض نمی کنه

### 🌓 تم پویای روز/شب
- پس زمینه و رنگ متن به صورت **کاملاً پیوسته** (نه پرشی) بر اساس ساعت محلیِ شهر انتخاب شده محو می شن — نه ساعت دستگاه کاربر
- نیمه شب (00:00) کمی تیره تر از بقیه ی ساعات شب
- تمام کارت ها (وضعیت فعلی، نمودار، ساعتی، هفتگی) دقیقاً هم زمان و هم رنگ با پس زمینه تغییر می کنن (با `color-mix()`)
- ساعت زنده ی سمت کاربر (تیک هر ثانیه) با منطقه ی زمانیِ واقعیِ شهر، با استفاده از `Intl.DateTimeFormat`

### 🎨 جلوه های بصری آب وهوا
- باران، پرتوهای خورشید، و **ابرهای چندلایه با عمق و سرعت متفاوت** برای حالت ابری (جلوه ی پارالاکس)
- تشخیص وضعیت هوا برای فعال سازی جلوه ها، به سه زبان فارسی/انگلیسی/اسپانیایی

### 🌐 چندزبانه
- رابط کاربری کامل به سه زبان: فارسی، انگلیسی، اسپانیایی
- صفحه ی لودینگ هم با همون سه زبان و امکان تغییر زبان پیش از بارگذاری کامل سایت

### 📊 نمایش داده
- نمودار دمای تعاملی (Chart.js)
- نقشه ی تعاملی موقعیت مکانی (Leaflet)
- کارت های ساعتی (امروز/فردا) و کارت های هفتگی با آیکون و ایموجیِ متناسب با وضعیت هوا

### 🔒 امنیت
- تمام درخواست ها به API های بیرونی روی HTTPS با بررسی فعال گواهی SSL
- اعتبارسنجی کامل ورودی ها (طول، محدوده ی مختصات جغرافیایی، whitelist نوع درخواست)
- محدودیت نرخ درخواست (Rate Limiting) بر اساس IP برای جلوگیری از سوءاستفاده
- جلوگیری از XSS با escape کردن تمام داده های دینامیک پیش از درج در DOM
- کلیدهای API فقط سمت سرور (هیچ وقت به کلاینت ارسال نمی شن)
- پوشه ی کش از دسترسی مستقیم وب محافظت شده (`.htaccess`)
- خاموش بودن نمایش خطاهای PHP به کاربر نهایی (فقط لاگ سمت سرور)

### ⚡ عملکرد
- کش فایلی سمت سرور (JSON) برای نتایج جست وجوی شهر — هر شهر فقط یک بار واقعاً جست وجو/ترجمه می شه
- کش سمت مرورگر (localStorage) برای داده ی آب وهوا (30 دقیقه)، با مدیریت خطای حالت خصوصی مرورگر
- لغو خودکار درخواست های قدیمی تر (`AbortController`) تا پاسخ یک جست وجوی قدیمی هیچ وقت روی جست وجوی جدیدتر ننشینه
- به روزرسانی ملایمِ پس زمینه ی داده ی آب وهوا هر 5 دقیقه، بدون نیاز به رفرش صفحه

### 📱 طراحی واکنش گرا
- تجربه ی کاربری یکپارچه و زیبا روی موبایل، تبلت و دسکتاپ

## 🚀 راه اندازی

1. مخزن رو کلون کن و فایل ها رو روی یک هاست PHP (با پشتیبانی cURL) آپلود کن.

2. یک فایل `config.php` کنار `backend.php` بساز:
(یا در فایل config.php من کلیدهات رو جایگذاری کن)

```php
<?php
define('WEATHER_API_KEY', 'your-WeatherAPI-key');
define('OPENWEATHER_API_KEY', 'your-OpenWeatherMap-key');
define('MYMEMORY_EMAIL', 'you@example.com');
```

3. مطمئن شو پوشه ی وب سرور اجازه ی ساخت پوشه ی `cache/` رو داره (برای کش جست وجوی شهر و محدودیت نرخ درخواست).

4. همین! سایت آماده ست.

> ⚠️ **هرگز `config.php` رو commit نکن.** این فایل و پوشه ی `cache/` از قبل توی `.gitignore` هستن.

## 📁 ساختار پروژه

```
.
├── index.php        # ساختار اصلی صفحه
├── style.css         # تمام استایل ها، شامل تم پویا و جلوه های بصری
├── script.js          # منطق سمت کلاینت: دریافت داده، تم، نقشه، نمودار، i18n
├── backend.php       # پراکسی امن به API های آب وهوا + جست وجوی شهر + کش
├── config.php        # کلیدهای API (شخصی، در گیت نیست)
└── cache/            # کش جست وجوی شهر و محدودیت نرخ (خودکار ساخته می شه)
```
